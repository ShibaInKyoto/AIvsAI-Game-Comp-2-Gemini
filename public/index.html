Volumetric Airship Engineering System

Every airship in Aethernaut is a dynamic, living voxel grid (15x11x23 cells, 16 block types, 7 flagship blueprints). Blocks possess distinct mass, buoyancy, armor, shield projection, and thrust. If blocks are blown away, the 3D Breadth-First-Search (BFS) fracture solver immediately detaches unanchored clusters into falling 3D debris!
